# Incursion — v1.2 planar 3D battlefield lab

Serve the root using any static HTTP server (e.g. `python3 -m http.server 8000`). Open localhost:8000. Requires WebGL 2. Three.js r170 is vendored locally with MIT license. No build or CDN.

## Milestone 3 review

The default scenario is **Procedural battlefield**. Enter a seed, choose Auto, Bastion, Frontier, Crossroads or Labyrinth, and load the preview (or Regenerate for a new seed). Inspect the full geography and corridor count before pressing Accept map. Preview freezes simulation; after acceptance undetected hostiles disappear. The procedural sector is 5,700 × 5,700 world units (about ten times the previous area). Use the upper-right minimap to pan and Fit scene to see the full sector; the inspector sits below the minimap in a non-overlapping review rail. The station starts at the exact center of a large open chamber. Large irregular asteroid banks create winding tunnels, widened combat pockets and open perimeter space; Bastion has two approaches, Frontier three, Crossroads four and Labyrinth three or four. Three wormhole candidates occupy distinct edges. All dense fields, sparse fields and nebulae are mutually exclusive with a minimum gap; navigation and visualization share their polygon geometry. Toggle Paths to inspect the selected ship's planned route and Range to see its effective weapon range. Select the ring-marked Command Ship, choose Move command ship, then click a destination across the map. Dense asteroid fields block hulls, sparse fields reduce movement speed to 65%, and nebulae reduce the source vessel's sensor and weapon ranges to 65%. Engage runs the existing battle sandbox with the new navigation rules. The preview shows three potential wormhole sites, one active; these are not a wave generator yet. The four green deposits show future mining sites (no economy or docking implemented yet).

The previous mixed fleet, counter duels, empty range and model review are still available. Their open-space behavior is unchanged. Normal ship speed is 270 units/s and approved combat ranges and stats are unchanged. Each carrier has six persistent cosmetic fighters. The command ship is twice ordinary model scale. Idle escorts follow, patrol and redistribute.

## Tests

Open `/tests/` for native browser checks, or run `node tests/run.mjs` for core and CPU geometry checks (Node 22+). The 1,000-map sweep can take tens of seconds. Append `?debug` for diagnostics. See DEVELOPMENT.md for actual validation and limitations. Milestone 4 (full fleet command), economy, construction and match loop remain gated on later approvals.
