# Incursion — v1.2 planar 3D combat sandbox

Serve the root using any static HTTP server (e.g. python3 -m http.server 8000). Open localhost:8000. Requires WebGL 2. Three.js r170 is vendored locally under vendor/ with MIT license. No build or CDN.

Milestone 2 review: default mixed fleet battle; press Engage. Select one of three counter duels (close or distant), Empty range for custom compositions, or Model review for the original artwork demo; press Load scenario. Place ships in the sandbox, inspect health and toggle labels, health bars and selected weapon range. In the mixed fleet scenario the ring-marked command ship is selected by default; use Move command ship and click a destination. Idle friendly combat escorts patrol and follow automatically. Inspect escorts without directly positioning them; uncommanded and hostile fixtures retain sandbox positioning. Pause, pan, zoom, change speed/quality, reset and use ?debug for diagnostics. Approved movement: 270 units/s; mobile attack ranges increased another 50% (three times the original ranges). Each carrier has six persistent cosmetic winged fighters that escort it, swarm its active target with blaster strikes, then return. Combat graphics are cosmetic; damage is fixed-step. Open /tests/ for native tests; node tests/run.mjs for core and CPU geometry/effect tests. See DEVELOPMENT.md for actual validation status. No terrain, fleet command, full economy or later milestones yet. Do not advance without approval.

The command ship model is now twice its former linear scale. Idle escorts redistribute into evenly spaced slots after combat or membership changes. A local hull-separation pass reduces crowding in the combat sandbox.
